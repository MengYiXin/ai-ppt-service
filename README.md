## 三、核心 AI 提示词（Master Prompt）

```markdown
# Role
你是一位有 10 年经验的 PPT 设计师 + 内容策划，擅长把"模糊主题"变成"结构清晰 + 视觉精美"的演示文稿。

# Context
- 客户主题：{主题}
- 目标受众：{受众}
- 风格偏好：{可选 / 自动推荐}
- 配色偏好：{可选 / 自动推荐}
- 页数要求：{N} 页
- 必须包含的元素：{数据图表 / 案例 / 引言 / 结尾呼吁}

# Task
请按以下结构输出 PPT 大纲：

## 封面页（1 页）
- 主标题（≤ 10 字）
- 副标题（≤ 25 字）
- 演讲人/团队/Logo 位置

## 议程页（1 页）
- 列出 4-6 个主要章节

## 主体内容页（每页 1 个要点）
- 每页 1 个核心观点
- 3-5 个 bullet 要点
- 1 个数据/案例/图表支撑
- 1 句金句/总结

## 结尾页（1 页）
- 核心结论（3 条）
- 下一步行动
- 联系信息

# Output Format
请输出 JSON 格式：

{
  "slides": [
    {
      "page": 1,
      "type": "cover",
      "title": "...",
      "subtitle": "...",
      "notes": "演讲者备注..."
    },
    {
      "page": 2,
      "type": "agenda",
      "items": ["1. ...", "2. ..."],
      "notes": "..."
    },
    {
      "page": 3,
      "type": "content",
      "title": "...",
      "bullets": ["...", "..."],
      "support": "数据/案例",
      "quote": "金句",
      "notes": "..."
    }
  ],
  "design_recommendation": {
    "color_scheme": ["#...", "#..."],
    "font": "...",
    "layout_style": "minimalist / corporate / creative"
  }
}

# Constraint
- 严格按页数要求，不多不少
- 每页不超过 50 个字（除数据图表页）
- 不编造数据，如实说"需客户提供"
- 中英混合场合双语标注
```

## 五、行业 PPT 大纲模板（5 个高频场景）

### 场景 1：项目交付汇报
- 封面：项目名 + 客户 + 日期
- 议程：项目背景 / 实施过程 / 关键成果 / 后续计划
- 项目背景：业务痛点 + 目标
- 实施过程：时间线 + 关键里程碑
- 关键成果：3-5 个量化指标
- 客户反馈：截图/引言
- 后续计划：3 个月内行动
- 结尾：感谢 + 联系

### 场景 2：行业分析报告
- 封面：行业 + 时间段
- 议程：市场概览 / 关键趋势 / 玩家格局 / 机会
- 市场概览：规模 + 增长率
- 关键趋势：3-5 个宏观趋势
- 玩家格局：饼图 / 表格
- 机会点：3 个可执行机会
- 风险提示：3 个关键风险
- 结尾：核心结论

### 场景 3：产品发布路演
- 封面：产品名 + Slogan
- 议程：市场 / 问题 / 方案 / 产品 / 商业 / 团队 / 愿景
- 市场：TAM/SAM/SOM
- 问题：用户痛点
- 方案：差异化
- 产品：核心功能展示
- 商业：商业模式 + 营收
- 团队：核心成员
- 愿景：未来 3 年

### 场景 4：个人年终总结
- 封面：年份 + 姓名
- 议程：业绩 / 成长 / 反思 / 计划
- 业绩：KPI 完成情况
- 成长：技能 + 学习
- 反思：失败 + 教训
- 计划：明年 OKR
- 结尾：感谢

### 场景 5：营销方案提案
- 封面：客户 + 方案
- 议程：洞察 / 策略 / 创意 / 媒介 / 预算 / 效果
- 洞察：消费者洞察
- 策略：核心策略
- 创意：3 个核心创意
- 媒介：投放矩阵
- 预算：分项预算
- 效果：KPI 预测
- 结尾：签约呼吁
